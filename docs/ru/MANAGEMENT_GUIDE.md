# Руководство по управлению

Языки: Русский (эта страница) | [繁體中文](../../MANAGEMENT_GUIDE.md) | [简体中文](../zh-cn/MANAGEMENT_GUIDE.md)

## Обзор

Динамически управляйте Cogs и функциями без перезапуска бота.

## 🔧 Команды

- `/manage reload` — перезагрузка одного модуля
- `/manage reload_all` — перезагрузка всех модулей
- `/manage sync` — синхронизация Slash‑команд
- `/manage status` — состояние бота/системы, загруженные модули
- `/manage logs` — последние логи
- `/manage restart` — перезапуск бота (systemd)
- `/manage shutdown` — корректное завершение
- `/manage eval` — выполнение кода (только владелец, осторожно)

## 🔒 Права

Доступ только у владельца бота.

## 🚀 Примеры

Фича: правки → `/manage reload` → при необходимости `/manage sync` → тест → `/manage status`

Крупные изменения: `/manage reload_all` → `/manage sync` → `/manage logs`

## ⚠️ Замечания

- Перезагрузка может сбрасывать внутреннее состояние модуля
- Подробные ошибки при сбоях
- `/manage eval` — высокий уровень прав

## 🔄 Преимущества hot‑reload

Без простоя, быстрая проверка, минимальное влияние, изоляция ошибок.
