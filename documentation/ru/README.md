## 📋 Обзор

Logivore — это мощный Discord бот, разработанный для комплексного мониторинга и управления системой. Построенный с передовыми возможностями автоматизации, он предоставляет инсайты в реальном времени о вашей серверной инфраструктуре, поддерживая надежность и безопасность корпоративного уровня.

### 🎯 Ключевые возможности

- **🔍 Мониторинг системы в реальном времени** - Статистика CPU, памяти, диска, сети
- **🚨 Интеллектуальная система предупреждений** - Проактивные уведомления о проблемах системы
- **🐳 Управление Docker** - Полное управление жизненным циклом контейнеров
- **🔄 Восстановление служб** - Автоматическое восстановление служб после системных событий
- **⚡ Управление SSL-сертификатами** - Автоматизированный мониторинг и обновление сертификатов
- **🌐 Многоязычная поддержка** - 8 языков с локализованными интерфейсами

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.8+
- Discord Bot Token
- Система Linux/Windows/macOS

### Установка
```bash
# Клонирование репозитория
git clone https://github.com/kaiyasi/Logivore.git
cd Logivore

# Установка зависимостей
pip install -r requirements.txt

# Настройка окружения
cp .env.example .env
# Отредактируйте .env с вашим токеном Discord бота и настройками

# Запуск бота
python main.py
```

### Развертывание Docker (опционально)
```bash
cd deploy/docker
docker compose up -d --build
```

## 🏗️ Архитектура

### 🔧 Технологический стек
- **Backend фреймворк**: Python 3.8+ с discord.py 2.0+
- **Мониторинг системы**: интеграция psutil, subprocess
- **Управление контейнерами**: интеграция Docker API
- **Управление SSL**: Let's Encrypt с Nginx Proxy Manager
- **Интернационализация**: многоязычная система на основе JSON
- **Конфигурация**: JSON с возможностью горячей перезагрузки
