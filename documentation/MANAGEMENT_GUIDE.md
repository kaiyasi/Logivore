# 🛠️ Bot 管理工具使用指南
 
語言：繁體中文（本頁） | [简体中文](zh-cn/MANAGEMENT_GUIDE.md)

## 功能概述

新增的 Bot 管理工具允許您在不重啟機器人的情況下動態管理模組和系統功能。

## 🔧 可用指令

### `/manage reload` - 重新載入單一模組
重新載入指定的 Cog 模組，適用於單一模組更新。

**選項：**
- System Monitoring - 系統監控模組
- Alerting - 告警系統模組
- Docker Management - Docker 管理模組
- Config Management - 配置管理模組
- Bot Management - 機器人管理模組

**使用場景：**
```
開發者修改了告警系統 → 使用 /manage reload Alerting
```

### `/manage reload_all` - 重新載入所有模組
一次性重新載入所有 Cog 模組，適用於大幅更新。

### `/manage sync` - 同步指令
手動同步 slash commands 到 Discord，適用於新增指令後。

### `/manage status` - 機器人狀態
顯示詳細的機器人狀態資訊：
- 機器人基本資訊
- 系統資源使用
- 已載入模組
- 配置狀態

### `/manage logs` - 查看日誌
顯示最近的機器人日誌（預設 20 行）

### `/manage restart` - 重啟機器人
如果機器人作為 systemd 服務運行，可以重啟服務。

### `/manage shutdown` - 關閉機器人
優雅地關閉機器人。

### `/manage eval` - 執行代碼 (危險)
僅限機器人擁有者使用，用於調試目的。

## 🔒 權限控制

所有管理指令僅限**機器人擁有者**使用，確保安全性。

## 🚀 開發流程示例

### 場景：新增功能後測試

1. **修改代碼** - 在任一 Cog 中添加新功能
2. **重新載入** - 使用 `/manage reload [模組名稱]`
3. **同步指令** - 如有新增指令，使用 `/manage sync`
4. **測試功能** - 直接測試新功能
5. **查看狀態** - 使用 `/manage status` 確認一切正常

### 場景：大幅更新

1. **完成所有修改**
2. **批量重新載入** - 使用 `/manage reload_all`
3. **同步指令** - 使用 `/manage sync`
4. **檢查日誌** - 使用 `/manage logs` 確認無錯誤

## ⚠️ 注意事項

1. **權限要求**: 只有機器人擁有者可以使用管理指令
2. **狀態保持**: 重新載入模組時，某些運行狀態可能會重置
3. **錯誤處理**: 如果重新載入失敗，系統會顯示詳細錯誤信息
4. **安全性**: `/manage eval` 指令具有完整系統訪問權限，請謹慎使用

## 🔄 熱重載優勢

- **零停機時間**: 不需要重啟整個機器人
- **快速測試**: 修改代碼後立即測試
- **狀態保持**: 其他模組繼續正常運行
- **錯誤隔離**: 單一模組錯誤不影響其他功能

這個管理系統大大提升了開發效率，讓您可以快速迭代和測試新功能！
